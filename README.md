# Simulador de Examen: Git Distribuido y APIs REST (80 Preguntas)

Simulador interactivo web para preparar el examen universitario sobre:
- **Git en Entornos Distribuidos** (Flujos Centralizado, Administrador-Integración, Dictador-Tenientes, forks, pull requests).
- **Conceptos de API y APIs Web** (HTTP/HTTPS, Express, REST, SOAP, GraphQL, RPC, Webhooks).
- **Beneficios de REST** (Rendimiento, Escalabilidad, Simplicidad, Modificabilidad, Portabilidad, Fiabilidad, Visibilidad).
- **Restricciones RESTful** (Cliente-Servidor, Stateless, Cacheable, Interfaz Uniforme, Sistema en Capas, Código bajo demanda).
- **Recursos, Representaciones y URLs** (Estructura de recursos, identificadores únicos/estables, buenas y malas prácticas).
- **Verbos HTTP y Códigos de Estado** (CRUD, HEAD, OPTIONS, códigos 1xx a 5xx).

## Características
- 80 preguntas de preparación intensiva.
- Formatos: Múltiple Choice (longitudes de respuestas variadas), Verdadero o Falso y Autocompletar.
- Explicaciones y definiciones teóricas de cada una de las opciones para cada pregunta.
- Modo Estudio (Feedback Inmediato) y Modo Examen (Simulacro con nota y diagnóstico).
- Optimizado para celulares y computadoras con Modo Oscuro y Claro.
